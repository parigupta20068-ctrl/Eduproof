# EduProof

### Prove Your Skills, Not Just Your Certificates.

EduProof is an AI-powered skill verification platform designed to evaluate a student's actual knowledge, practical skills, problem-solving ability, and understanding.

## Problem

Traditional certificates and academic marks do not always prove what a student can actually do. Recruiters and institutions often lack practical evidence of a student's skills.

## Our Solution

EduProof evaluates students through:

- Concept-based assessments
- Real-world practical challenges
- Secure code execution
- AI-powered viva
- Evidence-based skill evaluation
- Verified Skill Passport

## How It Works

Student → Concept Test → Practical Challenge → AI Viva → Skill Evaluation → Skill Passport

## Key Features

- AI-powered skill assessment
- Practical coding challenges
- AI Viva for explanation and understanding
- Evidence-based skill verification
- Shareable Skill Passport
- Student performance tracking

## Technology Stack

- Frontend: React / Next.js
- Backend: Python / FastAPI
- AI: LLM API
- Code Execution: Docker Sandbox
- Database: PostgreSQL / Firebase
- Authentication: Firebase Auth / JWT

## Current Prototype

The current version is a clickable UI prototype demonstrating the complete student assessment journey from skill selection to verified Skill Passport.
